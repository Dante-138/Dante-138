# Ian Gomes

Firmware developer working on embedded IoT systems, and Electrical Engineering student.

I write firmware in C for Nordic nRF52 and Espressif ESP32 devices: BLE, Wi-Fi, MQTT and
LoRaWAN connectivity, low-power design and RTOS task structure. Day to day I also work with
embedded Linux gateways, bench testing and validation, and the Python tools that support it.

## Stack

- **Languages:** C, Python, Shell
- **RTOS and SDKs:** Zephyr (nRF Connect SDK), FreeRTOS (ESP-IDF)
- **Hardware:** nRF52832, nRF52840, ESP32 family
- **Connectivity:** BLE, Wi-Fi, MQTT, LoRaWAN
- **Tools:** Git, Docker builds, J-Link, nrfjprog, CMake, West

## Projects

- [fw-nrf52840-ble-uart](https://github.com/Dante-138/fw-nrf52840-ble-uart): BLE to UART bridge with the Nordic UART Service, async UART with DMA.
- [fw-nrf52840-ble-beacon-scanner](https://github.com/Dante-138/fw-nrf52840-ble-beacon-scanner): iBeacon transmitter and BLE device scanner.
- [fw-nrf52840-ble-sensor-monitor](https://github.com/Dante-138/fw-nrf52840-ble-sensor-monitor): die temperature and supply voltage over BLE notifications.
- [tool-embedded-bench](https://github.com/Dante-138/tool-embedded-bench): Python tools for the bench: serial and MQTT logging, LoRa airtime, BLE advertising parser.
- [eng-software-quality](https://github.com/Dante-138/eng-software-quality): quality gate template for projects built with AI agents.
- [app-jarvis-voice-assistant](https://github.com/Dante-138/app-jarvis-voice-assistant): personal voice assistant in Brazilian Portuguese.
